ПУТЬ ПРОХОЖДЕНИЯ ДАННЫХ ОТ ЗАГРУЖЕННОЙ КАРТИНКИ ДО СКАЧАННОГО GIF:
===================================================================

ШАГ 1: ЗАГРУЗКА ИЗОБРАЖЕНИЯ
────────────────────────────
ПОЛЬЗОВАТЕЛЬ
    │
    │ 1. Выбирает изображения в браузере
    │ 2. Отправляет POST запрос на /upload
    ▼
NGINX API GATEWAY
    │
    │ 3. Перенаправляет запрос на image_processing:5001/upload
    ▼
IMAGE PROCESSING SERVICE
    │
    │ 4. Принимает файлы и проверяет формат
    │ 5. Генерирует уникальные имена файлов:
    │    IMG_{timestamp}_{unique_id}_{original_name}
    │ 6. Сохраняет файлы в /uploads/{session_id}/
    ▼
ОБЩАЯ ПАПКА UPLOADS
    │
    │ 7. Файлы сохранены в директории сессии
    ▼
IMAGE PROCESSING SERVICE
    │
    │ 8. Возвращает список новых имен файлов
    ▼
NGINX API GATEWAY
    │
    │ 9. Передает ответ пользователю
    ▼
ПОЛЬЗОВАТЕЛЬ
    │
    │ 10. Получает подтверждение загрузки


ШАГ 2: ОБРАБОТКА ИЗОБРАЖЕНИЙ (ПЕРЕУПОРЯДОЧИВАНИЕ/УДАЛЕНИЕ)
──────────────────────────────────────────────────────────
ПОЛЬЗОВАТЕЛЬ
    │
    │ 1. Изменяет порядок изображений или удаляет ненужные
    │ 2. Отправляет POST запрос на /reorder_images или /remove_image
    ▼
NGINX API GATEWAY
    │
    │ 3. Перенаправляет запрос в соответствующий микросервис
    ▼
IMAGE PROCESSING SERVICE
    │
    │ 4. Для переупорядочивания: переименовывает файлы с префиксами
    │    для сохранения нужного порядка
    │ 5. Для удаления: удаляет файл из директории сессии
    ▼
ОБЩАЯ ПАПКА UPLOADS
    │
    │ 6. Файлы переупорядочены или удалены
    ▼
IMAGE PROCESSING SERVICE
    │
    │ 7. Возвращает подтверждение выполнения операции
    ▼
NGINX API GATEWAY
    │
    │ 8. Передает подтверждение пользователю
    ▼
ПОЛЬЗОВАТЕЛЬ
    │
    │ 9. Получает подтверждение выполнения операции


ШАГ 3: ГЕНЕРАЦИЯ GIF
─────────────────────
ПОЛЬЗОВАТЕЛЬ
    │
    │ 1. Нажимает кнопку "Создать GIF"
    │ 2. Отправляет POST запрос на /generate_gif с параметрами:
    │    - duration: длительность кадра
    │    - loop: количество циклов
    │    - resize: размер изображения
    ▼
NGINX API GATEWAY
    │
    │ 3. Перенаправляет запрос на gif_generator:5002/generate_gif
    ▼
GIF GENERATOR SERVICE
    │
    │ 4. Получает параметры и session_id
    │ 5. Читает изображения из /uploads/{session_id}/ в нужном порядке
    │ 6. Применяет параметры (размер, длительность, циклы)
    │ 7. Создает анимированный GIF файл
    │ 8. Сохраняет как animation.gif в /uploads/{session_id}/
    │ 9. Оптимизирует GIF с помощью gifsicle
    ▼
ОБЩАЯ ПАПКА UPLOADS
    │
    │ 10. GIF файл сохранен в директории сессии
    ▼
GIF GENERATOR SERVICE
    │
    │ 11. Возвращает URL созданного GIF
    ▼
NGINX API GATEWAY
    │
    │ 12. Передает URL пользователю
    ▼
ПОЛЬЗОВАТЕЛЬ
    │
    │ 13. Получает URL для скачивания GIF


ШАГ 4: СКАЧИВАНИЕ GIF
──────────────────────
ПОЛЬЗОВАТЕЛЬ
    │
    │ 1. Нажимает кнопку "Скачать GIF" или переходит по URL
    │ 2. Отправляет GET запрос на /uploads/{session_id}/animation.gif
    ▼
NGINX API GATEWAY
    │
    │ 3. Читает файл из общей папки uploads
    ▼
ОБЩАЯ ПАПКА UPLOADS
    │
    │ 4. GIF файл найден и прочитан
    ▼
NGINX API GATEWAY
    │
    │ 5. Возвращает файл пользователю
    ▼
ПОЛЬЗОВАТЕЛЬ
    │
    │ 6. Получает и сохраняет GIF файл на устройстве

ОСОБЕННОСТИ АРХИТЕКТУРЫ:
========================

1. МИКРОСЕРВИСНАЯ СТРУКТУРА:
   • Каждый компонент отвечает за свою область функциональности
   • Легко масштабируется и поддерживается
   • Возможна независимая разработка и развертывание

2. УПРАВЛЕНИЕ СЕССИЯМИ:
   • Уникальный session_id для каждого пользователя
   • Изоляция данных между пользователями
   • Автоматическая очистка при создании новой сессии

3. ОБЩЕЕ ХРАНИЛИЩЕ:
   • Общая папка mounts между всеми контейнерами
   • Простое и эффективное решение для обмена файлами
   • Централизованное хранение файлов по сессиям

4. API GATEWAY:
   • Единая точка входа для всех запросов
   • Маршрутизация к соответствующим микросервисам
   • Обработка статических файлов и загрузок

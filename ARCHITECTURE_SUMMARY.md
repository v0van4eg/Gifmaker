# Архитектура приложения "Генератор GIF"

## Описание

В данном проекте содержатся файлы с визуализацией архитектуры приложения "Генератор GIF" - микросервисного веб-приложения для создания анимированных GIF из изображений.

## Структура проекта

1. **`architecture_diagram.md`** - Файл в формате Markdown с диаграммами Mermaid, описывающими архитектуру приложения и путь прохождения данных.

2. **`architecture_diagram.html`** - Интерактивный HTML-файл с визуализацией архитектуры приложения, включающий диаграммы Mermaid и подробное описание компонентов.

3. **`architecture_ascii.txt`** - Текстовый файл с ASCII-описанием архитектуры и пошаговым описанием пути прохождения данных.

## Архитектура приложения

Приложение построено по микросервисной архитектуре и включает следующие компоненты:

- **Web UI** (Flask, порт 5000): Веб-интерфейс пользователя, управление сессиями
- **Image Processing** (Flask, порт 5001): Обработка загрузки, удаления и переупорядочивания изображений
- **GIF Generator** (Flask, порт 5002): Генерация анимированных GIF с оптимизацией
- **Nginx API Gateway** (порт 8050): Маршрутизация запросов между компонентами
- **Общее хранилище файлов**: Общая папка `/uploads` для хранения файлов по сессиям

## Путь прохождения данных

1. **Загрузка изображений**: Пользователь → Nginx → Image Processing → Общее хранилище
2. **Обработка изображений**: Пользователь → Nginx → Image Processing → Общее хранилище
3. **Генерация GIF**: Пользователь → Nginx → GIF Generator → Общее хранилище
4. **Скачивание GIF**: Пользователь → Nginx → Общее хранилище → Пользователь

## Особенности архитектуры

- Микросервисная структура обеспечивает масштабируемость и поддерживаемость
- Управление сессиями с уникальными ID для изоляции данных пользователей
- Общее хранилище файлов между всеми микросервисами
- API Gateway для маршрутизации запросов
- Оптимизация GIF с помощью утилиты gifsicle
